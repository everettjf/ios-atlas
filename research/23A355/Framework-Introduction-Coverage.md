# How many cached frameworks have a sourced introduction?

The official iPhone 11 iOS 26.0.1 (`23A355`) cache contains **4,170** logical iOS images. Of these, **227** have an exact top-level path of the form `/System/Library/Frameworks/Name.framework/Name` with a non-underscore-prefixed name. This path pattern defines the scope of this pass; it is not a claim that every framework exposes an iPhone developer API.

The [introduction catalog](../../catalog/ios/23A355/library-intros.json) now links **218 of those 227** images to Apple Developer source material. Every entry records the exact install name, a short description, the page URL, the SHA-256 of the retrieved source document, and the check date. **178** descriptions are clearly marked short verbatim excerpts of at most 25 words; the others are authored summaries. The separate DriverKit cache has one additional sourced introduction, for **219** catalog entries total.

The five additions use [MetricKit](https://developer.apple.com/documentation/metrickit), [MusicKit](https://developer.apple.com/documentation/musickit), and [OpenGL ES](https://developer.apple.com/documentation/opengles) framework pages; the [IdentityLookupUI view-controller page](https://developer.apple.com/documentation/identitylookupui/ilclassificationuiextensionviewcontroller), whose framework landing page has no substantive abstract; and Apple's [archived iOS Core Audio guide](https://developer.apple.com/library/archive/documentation/MusicAudio/Conceptual/CoreAudioOverview/CoreAudioEssentials/CoreAudioEssentials.html) for OpenAL. These describe documented API families or types, not the runtime behavior of the exact cached images. The current Metal Performance Primitives programming guide concerns newer Metal 4 tensor capabilities on M5 hardware, so it is not used to describe the iPhone 11 image in this build.

The remaining **nine** top-level names are `BusinessChat`, `CoreServices`, `MetalPerformancePrimitives`, `MobileCoreServices`, `RealityFoundation`, `StickerFoundation`, `StickerKit`, `SwiftUICore`, and `Twitter`. These are **missing sourced introductions**, not absent cache images or proof that no documentation exists elsewhere. The direct Apple framework Markdown paths did not provide usable introductions for them in this pass.

The [shared-cache image explorer](https://xnu.app/ios-atlas/#images) offers **Browse introductions** and the `intro:` search prefix. A documentation page describes a documented API family or type, not the exact implementation, the complete method surface of the `23A355` binary, runtime loading, or whether a particular API is public on this iPhone. All 4,170 images still have a separate source-derived metadata overview and an Objective-C method result. Other private frameworks, libraries, support components, and the nine names above remain in the [research TODO](../../docs/research-todo.md) for functional investigation with suitable primary evidence.
