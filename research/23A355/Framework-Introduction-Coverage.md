# How many cached frameworks have a sourced introduction?

The official iPhone 11 iOS 26.0.1 (`23A355`) cache contains **4,170** logical iOS images. Of these, **227** have an exact top-level path of the form `/System/Library/Frameworks/Name.framework/Name` with a non-underscore-prefixed name. This path pattern defines the scope of this pass; it is not a claim that every framework exposes an iPhone developer API.

The [introduction catalog](../../catalog/ios/23A355/library-intros.json) now links **213 of those 227** images to matching Apple Developer framework pages. Every entry records the exact install name, a short description, the page URL, the SHA-256 of the retrieved Markdown page, and the check date. **178** descriptions are clearly marked short verbatim excerpts of at most 25 words; the others are authored summaries. The separate DriverKit cache has one additional sourced introduction, for **214** catalog entries total.

The remaining 14 top-level names are `BusinessChat`, `CoreServices`, `IdentityLookupUI`, `MetalPerformancePrimitives`, `MetricKit`, `MobileCoreServices`, `MusicKit`, `OpenAL`, `OpenGLES`, `RealityFoundation`, `StickerFoundation`, `StickerKit`, `SwiftUICore`, and `Twitter`. Thirteen did not yield a matching Apple framework overview at the exact documentation path during this pass; `IdentityLookupUI` yielded a page without a substantive abstract. These are **missing introductions**, not absent cache images or proof that no documentation exists elsewhere.

The [shared-cache image explorer](https://xnu.app/ios-atlas/#images) offers **Browse introductions** and the `intro:` search prefix. An Apple framework page describes the documented API family, not the exact implementation, the complete method surface of the `23A355` binary, runtime loading, or whether a particular API is public on this iPhone. All 4,170 images still have a separate source-derived metadata overview and an Objective-C method result. Other private frameworks, libraries, support components, and the 14 names above remain in the [research TODO](../../docs/research-todo.md) for functional investigation with suitable primary evidence.
