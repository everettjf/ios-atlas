# Which published device files have content-format labels?

Target: the currently jailbroken iPhone 11 (`iPhone12,1`), iOS 26.0.1 (`23A355`). The public device path index has **225,778 regular files** beneath reviewed system and jailbreak prefixes. Read-only `file-5.43` passes over the complete base-root, jailbreak, and Developer views produced one description for every one of those public files. The [format catalog](../../catalog/ios/23A355/live-file-formats.json.gz) links each reviewed path to a fixed category; it contains no raw `file` description. All **225,778 / 225,778** public regular-file paths have a category. Four type-pass paths do not belong to the reviewed public file set and are excluded.

The type-output SHA-256 values are `488594c6195f1a7b74d6ab59d63b78cd726f73bb7586d06c362e526f2cc475f4` for 219,216 base-root files, `a5c4864bd9020552b00804c73aa619129ca2526193f253cd55ada7dde18042bf` for 6,449 jailbreak files, and `69f93753c280cbd3631d030055fb873491a45a74dcd4d941fd73fe3d8cf754c0` for 117 Developer files. The [collector](../../tools/catalog_live_file_formats.py) rejects truncated NUL pairs, duplicate paths, missing public files, and categories outside its fixed vocabulary. The site builder checks the complete regular-file path set and category totals again before publication.

The public categories include **3,623 Mach-O or mixed-container descriptions**, **99 script or makefile descriptions**, and **six ELF descriptions**. Other large groups include 132,034 archive or compressed files, 36,773 binary property lists, and 12,444 XML files. These are format labels, not evidence that each file is executable or loaded. A raw `file` description can contain private strings, so the site shows only the reviewed category and the already-public path. Search `format:script`, `format:macho`, or another category in **On-device files**.

An [exact path-set reconciliation](Public-MachO-File-Reconciliation.md) accounts for all 3,623 public Mach-O-like results: 3,622 byte-verified ordinary binaries plus one byte-matched mixed Metal container. The site build rejects a gap in this public set.

The 99 script/makefile and six ELF paths also have [fixed format details](Live-Alternate-Code.md). These are signature-derived labels, not a claim about execution or source-level behavior.

The separate private Data and Mobile data type passes found six and 1,503 script descriptions, plus one and 299 ELF descriptions respectively. Those are **aggregate observations only**: the Data path set was stable across its snapshot and type pass, while Mobile data had 34 additions and 34 removals. Their private paths, raw descriptions, contents, and hashes are not published. The 73 protected directories remain outside the observed type results.

`file` detects recognizable signatures and shebangs. It does not enumerate scripts stored inside archives, code embedded in databases or assets, or dynamically generated code. The two mixed Metal containers contain Mach-O signatures but are not ordinary standalone executable pages. Exact Mach-O identities and logical dyld shared-cache images are indexed separately. Deeper code behavior remains on the [research TODO](../../docs/research-todo.md).
