## Reproduce and limits

With the saved, pinned root SSH route to this exact device, run `find /rootfs/private/preboot -xdev -type f -exec file -0 -0 -- {} +` and keep the output under ignored `.local`. Check its NUL-delimited path set against the private Preboot scan, then compare candidates with the public standalone identity records. Hash and acquire the unmatched file privately, verify its local SHA-256 against the device-side result, and compare that hash with `/System/Library/Frameworks/QuartzCore.framework/default.metallib` in the mounted official SystemOS image. The header can be inspected with `tools/catalog_standalone_macho.py`'s fat and thin Mach-O parsers. Do not publish the physical Preboot path.

This pass covers **reachable regular files in one completed mount view**. It does not decode the Metal payload, prove GPU execution or runtime loading, classify scripts or every embedded-code format, or say anything about inaccessible directories in the two partial data-volume views. The [mount coverage](../../catalog/ios/23A355/live-coverage.json) and [collection procedure](../../docs/live-device-collection.md) retain those boundaries.
