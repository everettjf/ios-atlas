# How does a SpringBoard window scene reach startup completion code?

Target: iPhone 11 (`iPhone12,1`), iOS 26.0.1 (`23A355`), SystemOS arm64e cache UUID `C0A7E671-35E1-3E6C-842D-FCE4E0A08C7E`. All instruction addresses below come from the cached `/System/Library/PrivateFrameworks/SpringBoard.framework/SpringBoard` image (UUID `8676BE2A-9484-3492-888E-7DE10333250F`), extracted locally with `ipsw dyld extract` (SHA-256 `7732a59763b6fa34a52bfe8531d6dc0fcfa69761f6a96f438c0cda3363bb20be`). The executable bytes are not published.

[Apple documents the scene-delegate connection callback](https://developer.apple.com/documentation/uikit/uiscenedelegate/scene%28_%3Awillconnectto%3Aoptions%3A%29). The classes below are private SpringBoard classes, so the public documentation supplies context for the callback shape, not proof of their internal behavior.

## Observed static path

1. `SBEmbeddedDisplayWindowSceneDelegate` is a subclass of `SBAbstractWindowSceneDelegate` in the exact class dump. Its `scene:willConnectToSession:options:` implementation starts at `0x21dcf46a4`, calls `objc_msgSendSuper2` at `0x21dcf4730`, and sends `noteMainSceneConnected:` at `0x21dcf4798` after a role comparison. The superclass implementation at `0x21d7976dc` conditionally sends `_commonSceneSetupForScene:` at `0x21d797814`.
2. The superclass's `_commonSceneSetupForScene:` at `0x21d798978` sends `_configureForConnectingWindowScene:windowSceneContext:` at `0x21d7989d0`. The embedded delegate overrides that selector at `0x21dcf3b48`. Objective-C dispatch makes this a candidate connection between the two bodies; no runtime receiver trace proves the override was chosen on the phone.
3. The embedded delegate's configuration body constructs a block whose invoke address is `0x21dcf3f20` (`0x21dcf3e4c–0x21dcf3e60`) and passes it to `objc_retainBlock` at `0x21dcf3e8c`. The retained block is stored through an instance-field offset at `0x21dcf3e98–0x21dcf3e9c`. The exact later caller of this block is not established here.
4. At the start of the block, a weakly held object is loaded and checked; a null result branches away at `0x21dcf3f50`. Otherwise, at `0x21dcf3f68`, the block sends `_completeStartupAfterMainSceneConnect:` to a global object and passes a captured window scene as its argument. The `SpringBoard` class implements that selector at `0x21d6a41d8`; dynamic dispatch to that particular IMP is not proven by the selector name alone.
5. Within that 5,770-line implementation, selected call sites show a `dataRecoveryRequired` check (`0x21d6a43b0`) whose false branch skips `performDataRecovery` (`0x21d6a4420`), followed later in code by `setWindowScene:` (`0x21d6a44f8`), `_startBulletinBoardServer` (`0x21d6a7b28`), and `setHasFinishedLaunching:` (`0x21d6a8818`). These are bounded instruction observations, not a complete control-flow or side-effect analysis.

Separately, `SBEmbeddedScenesConnectionManager` implements `noteMainSceneConnected:` at `0x21d8231b4`; it stores a scene reference and sends `_reevaluateSceneConnection` at `0x21d8232b4`. Its reevaluation body includes a `completeStartupAfterAllEmbeddedScenesConnect` send at `0x21d82377c` behind conditional branches. The relationship between this manager path and the retained configuration block needs a focused callback/ownership trace before a single execution timeline can be claimed.

## Boundary and reproduction

The code establishes a superclass setup call, an override with a retained block, and the block's candidate SpringBoard startup-completion send. It does **not** establish the block's invocation timing, which scene role was present, whether data recovery ran, or the connected device's runtime path. No tweak hook is selected.

Verify the image SHA-256 and UUID above, then disassemble the named functions with `xcrun llvm-objdump -m -d --dis-symname '<symbol>' .local/rea/extracted/SpringBoard`. The symbols are `-[SBEmbeddedDisplayWindowSceneDelegate scene:willConnectToSession:options:]`, `-[SBAbstractWindowSceneDelegate scene:willConnectToSession:options:]`, `-[SBAbstractWindowSceneDelegate _commonSceneSetupForScene:]`, `-[SBEmbeddedDisplayWindowSceneDelegate _configureForConnectingWindowScene:windowSceneContext:]`, `___94-[SBEmbeddedDisplayWindowSceneDelegate _configureForConnectingWindowScene:windowSceneContext:]_block_invoke`, and `-[SpringBoard _completeStartupAfterMainSceneConnect:]`. The [earlier startup note](SpringBoard-Post-Launch.md) covers the application launch callback before this scene-specific path.
