# Which named code symbols are visible in the iOS shared cache?

Target: all **4,170** logical images in the intact arm64e iOS dyld shared-cache family from the official iPhone 11 iOS 26.0.1 (`23A355`) IPSW, SHA-256 `2773217713e94b81fbbaa6ecb6b7e87fb176f58f5edefdb868d8d71ec6547bd2`. Cache family UUID: `C0A7E671-35E1-3E6C-842D-FCE4E0A08C7E`. This excludes the separate DriverKit cache and physical Mach-O files outside the cache.

An `ipsw` 3.1.739 pass with `dyld macho --symbols --demangle` yielded **6,585,655 unique named `__text` symbol records** in **3,798 images**. The other **372** images had no matching named record. The raw output contained **577,724 additional duplicate rows** with identical address, name, visibility, and segment; the catalog counts them without repeating them in the browser. Of the unique records, **2,734,567** have the textual shape of an Objective-C method (`-[Class selector]` or `+[Class selector]`). This is a name-pattern count, not a verified subset of the separate [3,065,801-entry Objective-C method catalog](Method-Catalog-Coverage.md), and the two totals must not be added as if they were disjoint functions.

Every physical member of the 80-file cache family was checked by size and complete SHA-256 against the official IPSW inventory before collection. Each image's Mach-O UUID was checked against that inventory. Every published symbol address falls inside an executable segment's `__text` section for that exact image. The catalog keeps the SHA-256 of each raw symbol dump and Mach-O table of contents, along with counts of duplicate, unnamed, out-of-section, and undecodable rows. In this pass the latter three counts are zero. Raw command output and resumable checkpoints stay outside Git.

The [shared-cache image explorer](https://xnu.app/ios-atlas/#images) shows the symbol count for each image. Selecting **Browse named `__text` symbols** loads one of 128 compressed buckets; the list can be searched by name, address, visibility, or segment. Foundation has **39,492** named records, of which **10,663** match the Objective-C name pattern. SpringBoard.framework has **69,889** named records, of which **53,010** match that pattern. The site keeps the symbol list beside, rather than inside, the separate Objective-C method view.

A symbol-table name can denote a private implementation detail, alias, compiler-generated label, or other code-section label. Stripping may remove names while leaving code. This index is a horizontal map of visible names, **not** a complete function list, public API list, description of implementation, runtime trace, or verified tweak hook. Functional introductions for documented framework families are tracked separately in the [framework coverage note](Framework-Introduction-Coverage.md); per-library implementation questions remain on the [research TODO](../../docs/research-todo.md).

The aggregate source is [`ios-cache-symbols.json.gz`](../../catalog/ios/23A355/ios-cache-symbols.json.gz). To regenerate it from the exact locally extracted cache:

`python3 tools/catalog_ios_cache_symbols.py --cache-main .local/cache/23A355__iPhone12,1/dyld_shared_cache_arm64e --dyld-catalog catalog/ios/23A355/dyld.json --workdir .local/ios-cache-symbol-work --output catalog/ios/23A355/ios-cache-symbols.json.gz --workers 8`
